# Developer & Agent Guidelines

## 1. Approval Policy ("Gas" Requirement)
- Jangan pernah memulai pengubahan kode / eksekusi plan sebelum user memberikan persetujuan eksplisit (contoh: kata "gas", "eksekusi", atau "proceed").
- Diskusi atau pertanyaan seputar plan TIDAK BOLEH dianggap sebagai persetujuan untuk mulai koding.

## 2. Test & Lint Execution Policy
- Dilarang menjalankan `npm test`, `vitest`, `npm run lint` secara otomatis di sela-sela task.
- Test dan lint HANYA dijalankan satu kali di akhir saat diminta oleh user atau tepat sebelum commit.

## 3. Communication Style
- Ringkas, disiplin, dan langsung mendengarkan poin-poin yang ingin dipastikan oleh user.
